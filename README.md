# Football App

A small matchday app for logging scores and seeing a table. It runs in the browser and keeps your matches on this phone or computer.

## On your phone

1. Install the GitHub app and sign in as `tayolanrewaju`.
2. Open this repository: [football-app](https://github.com/tayolanrewaju/football-app).
3. To edit the code, open [github.dev/tayolanrewaju/football-app](https://github.dev/tayolanrewaju/football-app).

## On this computer

Open `index.html` in a browser. Use **Matches** to change a score, **Table** to see the standings, and **Add** to create a fixture.
