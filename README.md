# NINETY

A matchday companion for logging football scores and watching the league table update. Runs entirely in the browser and keeps your fixtures on this device.

## Features

- **Matches** — nudge live scores up or down, mark fixtures live / full time / reset
- **Table** — standings from finished and live results (points, GD, form columns)
- **Add** — create a new fixture; data persists in `localStorage`

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
