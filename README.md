# NINETY

A matchday companion with favourites, transfer radar, match notifications, player market, and an AI you can ask football questions. Runs in the browser and keeps your data on this device.

## Features

- **Matches** — live scoreboard, favourite clubs floated to the top
- **Transfers** — big incoming deals and rumour heat for clubs you follow
- **Market** — player valuations and momentum
- **Favourites** — star teams to personalise the board and alerts
- **Alerts** — browser notifications before favourite kickoffs + hot transfer pings
- **Ask AI** — ask about transfers, values, fixtures, or rules in plain English
- **Table / Add** — standings from results, and new fixtures with optional notify time

## Run it

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

Allow notifications when prompted if you want match and transfer alerts.

## Note on AI & live data

Transfer and market boards ship with a curated snapshot so the app works offline. NINETY AI answers from that board plus your favourites, fixtures, and football facts — no API key required.
